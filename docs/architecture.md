# 초기 아키텍처

## 컨텍스트

```text
외부 콘텐츠
  → React Web/PWA
  → Spring Boot API
     ├─ 콘텐츠 분석
     ├─ 관광 데이터 정규화·매칭
     ├─ 장소와 컬렉션
     └─ 여행 일정과 경로 생성
  → PostgreSQL/PostGIS + Redis
```

## 백엔드 모듈 경계

| 패키지 | 책임 |
| --- | --- |
| `auth` | 인증과 토큰 |
| `user` | 사용자와 여행 설정 |
| `share` | 공유 URL 접수와 분석 작업 |
| `content` | 메타데이터와 콘텐츠 분석 |
| `place` | 정규화된 장소 |
| `tourism` | 한국관광공사 API 연동 |
| `collection` | 사용자 컬렉션 |
| `map` | 공간 조회 |
| `itinerary` | 일정과 방문 순서 |
| `recommendation` | 주변 장소와 대체 장소 |
| `notification` | 분석 완료와 일정 알림 |
| `common` | 공통 응답, 오류, 설정 |

초기에는 패키지 사이의 직접적인 DB 엔티티 공유를 피하고 서비스 인터페이스를
통해 협력합니다. 비동기 분석은 우선 DB 작업 테이블과 Spring 비동기 실행으로
구현하고, 처리량이 확인된 뒤 메시지 브로커 도입을 검토합니다.

## 초기 구현 순서

1. 개발 기반과 인증
2. URL 공유 접수 및 분석 상태
3. 장소 저장과 컬렉션
4. 관광공사 API 매칭
5. 지도 조회
6. 일정 생성과 방문 가능성 검증
